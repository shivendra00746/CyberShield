
# CyberShield

### Cybersecurity Monitoring Dashboard

CyberShield is a student project designed to demonstrate basic cybersecurity monitoring, security event analysis, and incident alerting.

## Project Features

- Security dashboard
- Sample security log display
- Failed login detection demonstration
- Security alert display
- Incident response workflow overview

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- CSV

## Project Status

Currently under development.

## Disclaimer

This project uses sample data for educational and demonstration purposes. It does not provide live attack detection or automated incident response.
